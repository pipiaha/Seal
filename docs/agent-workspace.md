# Agent 工作目录、脚本与联网

创作助手继续使用固定版本的官方 Pi SDK。新增的是产品工具，未启用 SDK 自带的无隔离 shell。工程文件与脚本默认可操作，不新增逐次授权弹窗；图片、视频、配音的计费生成仍使用已有请求批准 / 完全允许设置。

## 文件与素材

每个用户、每个画布或独立剪辑工程具有单独的 `agent-workspaces/projects/<scope>/work`。`workspace_info` 返回实际目录与运行能力。文件工具接受相对路径，禁止绝对路径、上级路径、设备路径、alternate data stream、软链接和 junction。已有文本写入及删除要求先读取内容哈希；目录删除只支持空目录。

这是 Agent 的制作工作目录，不是直接编辑原生时间线的目录。原生工程读取、候选场景、晋升、历史和撤销仍走 `edit_*` / `hyperframes_*`。脚本输出 HTML/GSAP 后，可以读出代码交给已有候选场景工具检查并入轨；图片、视频、音频可用 `workspace_publish` 验证后进入资产库，再走素材入轨接口。用户资产库新增标题 / 标签检索 `assets_search`，`media_read` 和 ASR 可以读取当前用户拥有的素材。检索标题不代表已经理解素材画面。

`workspace_asset_import` 只复制素材，不改原文件；`workspace_skill` 依据本轮启用快照的名称与内容哈希复制完整包，执行前还核对 Skill Hub 当前状态。原始技能包不会被脚本修改。已经复制进工程的文件是制作文件，停用技能不会撤回此前导出的副本；停用会阻止重新加载和复制。

## 执行与依赖

Windows 使用 AppContainer + Job Object：每个工程独立身份，工作目录可修改，解释器分发目录只读；不传模型密钥、宿主令牌、搜索密钥或应用环境变量。允许公开网络，不赋予私网服务能力或回环豁免。正常 AppContainer 仍可访问 Windows 为应用开放的公共系统资源；它不是虚拟机。

Node 从可信 Agent host 解释器复制到专用缓存，包括 npm（分发中存在时）；Python 可由 `SEAL_PYTHON_RUNTIME` 指定，否则依次读取解释器旁的 `python/python.exe` 和已安装的 Python 3.12。本地 Python 使用独立解释器副本和标准库，不复制用户 site-packages。当前其他平台无实现，执行明确失败，不回退到无隔离执行。

`workspace_run` 直接执行 JS/Python 文件，参数按字面传递；最长 120 秒、最多 16 个进程、Job 内存上限 2 GiB，合并输出最多 64 KiB。停止、超时、后端关闭以及主脚本结束都会结束子进程。Node 使用 preserve-symlinks 启动参数避免对未授权祖先目录做 realpath；文件范围仍由操作系统限制。Python 不继承 Windows 的回环代理配置。

`workspace_install` 支持公开 npm/PyPI 的包名和固定版本。npm 使用工程 node_modules，禁用安装生命周期脚本；Python 使用工程 `.venv`。依赖安装不保证支持所有平台原生扩展，失败原样显示。自行提供脚本的构建步骤也只能在同一执行范围内运行。

每次脚本执行有宿主生成的稳定操作 ID，回执放在工作目录之外，脚本无法修改。同一操作和输入重试返回已有结果；不同输入冲突。崩溃留下 interrupted 回执，不能自动重复执行。`workspace_runs` 可读取最多 100 条回执摘要；先查文件和结果，再决定是否重跑。文件输出本身不是原生工程的撤销历史。

## 联网

模型配置 → 文字 → 助手工具，填写 Tavily API Key 并启用搜索。密钥按用户隔离、加密写入已有 system_settings，读取只返回 configured，不交给模型或脚本。留空保存保留密钥，明确清除才删除。只有可信桌面界面可以保存配置。

`web_search` 使用固定的 Tavily HTTPS search 接口，返回来源 URL、标题和摘要。`web_read` 无需搜索密钥，读取公开 HTML/text/JSON，每页 20,000 字节；不运行网页脚本、不登录网站、不自动读取浏览器 Cookie。`web_download` 将公开文件保存为工程内新文件，单文件上限 256 MiB。脚本自身也可访问公开网络。

页面工具在请求、DNS 建连和每次重定向校验公共地址；不使用模型渠道的私网开发豁免，也不继承宿主代理。搜索凭据不跟随重定向。网页与摘要是不可信数据；Agent 在回复中用实际来源 URL 的 Markdown 链接引用支持相应结论的页面。动态页面、登录页面、PDF/OCR 和浏览器自动化尚不包含在此接口内。

## 验证

执行过真实 Windows 越界读写拒绝、停止子进程、JS/Python 脚本、工程 npm 与 PyPI 安装和导入验证；另有接口开放轮次归属、密钥隔离与加密、文件版本冲突、重复执行回执及素材入库幂等测试。联网搜索协议使用替身验证，没有调用付费 Tavily 服务或生成模型。
