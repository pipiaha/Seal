# Agent 工作目录、脚本与联网

创作助手继续使用固定版本的官方 Pi SDK，通过产品工具执行脚本。脚本默认采用本机完全访问，不新增逐次授权弹窗；图片、视频、配音的计费生成仍使用已有请求批准 / 完全允许设置。这两个控制互相独立。

## 文件与素材

每个用户、每个画布或独立剪辑工程具有单独的 `agent-workspaces/projects/<scope>/work`。`workspace_info` 返回实际目录与运行能力。文件工具接受相对路径，禁止绝对路径、上级路径、设备路径、alternate data stream、软链接和 junction。已有文本写入及删除要求先读取内容哈希；目录删除只支持空目录。

这是 Agent 的制作工作目录，不是直接编辑原生时间线的目录。原生工程读取、候选场景、晋升、历史和撤销仍走 `edit_*` / `hyperframes_*`。脚本输出 HTML/GSAP 后，可以读出代码交给已有候选场景工具检查并入轨；图片、视频、音频可用 `workspace_publish` 验证后进入资产库，再走素材入轨接口。用户资产库新增标题 / 标签检索 `assets_search`，`media_read` 和 ASR 可以读取当前用户拥有的素材。检索标题不代表已经理解素材画面。

`workspace_asset_import` 默认复制素材，保留原文件；`workspace_skill` 依据本轮启用快照的名称与内容哈希复制完整包，执行前核对 Skill Hub 当前状态。复制机制本身不改原始包，但完全访问脚本有系统账户的文件权限，不能承诺它无法修改原文件。停用技能阻止重新加载和复制，不撤回已有制作文件。原生 HyperFrames 和 Hypit 素材导入允许当前用户拥有的已保存素材，不要求事先在对话中 `@`；工程、资源归属和版本保护继续生效。

## 执行与依赖

脚本使用当前系统账户的普通进程，默认工作位置是当前工程目录；该目录不是安全边界。脚本可以读写系统账户有权限的其他文件，并访问本机及网络服务，不申请管理员权限。运行环境只保留系统路径、语言、网络代理/证书配置和明确的媒体工具路径，另设置工程内临时目录与依赖缓存；不直接继承应用的模型 Key、宿主令牌、搜索 Key 或 Node/Python 注入钩子。环境过滤不限制脚本自行读取磁盘，不能理解成凭据文件受到隔离保护。

直接使用配置好的 Node/Python 解释器，不再复制解释器或修改工作目录 ACL。Python 仍可由 `SEAL_PYTHON_RUNTIME` 指定，否则使用已有解释器发现逻辑；工程存在 `.venv` 时优先使用该解释器。Windows 通过 Job Object 管理进程树，macOS/Linux 使用进程组；其他平台明确拒绝执行。跨平台实现不代表相应发行包已完成实机验收。

`workspace_run` 直接执行 JS/Python 文件，参数按字面传递；最长 120 秒，合并输出最多 64 KiB。停止、超时、后端关闭以及主脚本结束会清理受管理的进程树。Windows 在暂停状态下创建进程并加入 Job 后才运行；完全访问不再设置 AppContainer、原16进程/2GiB或 UI 沙箱限制。macOS/Linux 清理所属进程组，主动脱离进程组的程序不具有同等保证。运行失败在工具回执和界面投影为错误。

`workspace_install` 支持 npm/PyPI 的包名和固定版本。内置安装助手默认使用工程 node_modules、禁用 npm 生命周期脚本，Python 使用工程 `.venv`；运行环境保留正常系统 PATH 和代理。完全访问脚本可自行调用系统命令和安装步骤，无额外脚本审批。依赖安装不保证支持所有原生扩展，失败原样显示。

每次脚本执行有宿主生成的操作 ID，回执仍放在工作目录之外用于组织和恢复，但不再宣称脚本无法修改该位置。同一操作和输入重试返回已有结果；不同输入冲突。崩溃留下 interrupted 回执，不能自动重复执行。`workspace_runs` 可读取最多100条摘要；先查文件和结果，再决定是否重跑。文件输出本身不是原生工程的撤销历史，原生轨道继续用已有编辑接口。

## 联网

模型配置 → 联网搜索，启用后选择 Tavily 或 DeepSeek 原生搜索。Tavily 填写独立 API Key；DeepSeek 可以复用已有启用渠道的密钥，或独立填写。复用渠道时每次搜索读取当前密钥，不复制到搜索配置；所选渠道停用、删除或缺少密钥会明确提示。两家独立密钥分别加密保存，切换服务、留空保存保留已有密钥，清除只作用于当前服务。读取返回 configured 和脱敏配置，不交给模型或脚本。旧单服务配置自动保留为 Tavily。只有可信桌面界面可以保存配置和使用测试入口。

`web_search` 与主对话模型独立，按配置使用固定的 Tavily HTTPS search 接口，或 DeepSeek Anthropic 兼容 Messages 接口。DeepSeek 默认基础地址为 `https://api.deepseek.com/anthropic/v1`、模型为 `deepseek-v4-flash`；每次搜索额外调用模型，上限4096输出 Token、3次服务端搜索，超时90秒。只解析原生 `web_search_tool_result` 中的 URL、标题、日期，以及对应引用摘要，不把模型正文当成真实搜索结果。无原生结果块明确失败，不自动切换服务或重复付费请求；结果数量可配置1–10条。搜索失败不会中断无需密钥的网页读取能力。

测试搜索使用已保存并启用的配置，仅用户点击才执行真实调用，支持停止，显示来源与实际错误。`web_read` 无需搜索密钥，读取公开 HTML/text/JSON，每页20,000字节；不运行网页脚本、不登录网站、不自动读取浏览器 Cookie。`web_download` 将公开文件保存为工程内新文件，单文件上限256 MiB。普通进程脚本另按当前账户网络权限执行，可以使用本机服务和代理。

搜索连接对 `api.deepseek.com`、`api.tavily.com` 两个官方 HTTPS 服务兼容本机 TUN 代理使用的 `198.18.0.0/15` Fake-IP DNS，TLS 继续校验原始域名，不放行其他域名、普通内网地址或地址字面量。网页读取和下载保持公开地址策略。搜索错误使用结构化业务错误返回，区分网络失败、超时、供应商拒绝、格式错误和缺少原生结果；不把上游响应体或密钥公开到错误消息。匿名网络探测仅验证官方接口可达，不代表凭证有效或真实搜索已完成。

页面工具在请求、DNS 建连和每次重定向校验公共地址；不使用模型渠道的私网开发豁免，也不继承宿主代理。搜索凭据不跟随重定向。网页与摘要是不可信数据；Agent 在回复中用实际来源 URL 的 Markdown 链接引用支持相应结论的页面。动态页面、登录页面、PDF/OCR 和浏览器自动化尚不包含在此接口内。

## 验证

本机完全访问专项验证覆盖合成工程外文件读写、本机 HTTP 服务、干净环境、字面参数、回执复用、取消/超时/关闭/正常退出后的子进程清理。旧 AppContainer 测试只验证保留的隔离 helper，不代表默认执行模式。原生素材接口仍测试工程归属、其他用户素材拒绝和无需引用即可进入资源校验。联网搜索没有使用真实付费 Tavily 或生成模型。
