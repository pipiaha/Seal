# Seal 助手多模态输入核对

日期：2026-10-09。沿用已固定版本的官方 Pi SDK、现有资产库、ASR 任务与 HyperFrames 运行端。

## 当前支持范围

| 用户输入 | 实际读取方式 | 条件与边界 |
| --- | --- | --- |
| 上传、粘贴、拖入图片 | 前端解码并限尺寸，官方 `session.prompt(..., { images })` 发送真实像素 | 模型需开启图片输入；PNG/JPEG 请求，最多 8 张，遵循模型更小的限制；GIF 只读静态画面 |
| `@` 图片、选中画布图片 | 从所属资源或当前项目绘图预览读取像素 | 不靠文件名推断；选区图片仅在视觉模型启用时自动附带 |
| 添加 MP4/WebM 视频 | 原文件保存到资产库，当前回合加入所属资产引用；Agent 用 `media_read` 获取真实信息、带时间戳的抽帧 | 默认均匀抽取 3 个时间点，可指定时间；最多 8 个且受模型图片数限制；视频讲话另用 ASR |
| 添加 MP3/WAV/OGG/M4A 音频 | 原文件保存到资产库，`media_transcribe` 创建或复用持久 ASR 任务，`media_transcription` 查询真实结果 | 本地 Whisper Base 或已配置服务；返回分段/近似词级时间；不能识别音乐类别和音效 |
| `@` 或选择画布音视频、`@` 资产库音视频 | 当前画布节点/已验证资产 ID 进入本轮附件说明，工具读取所属原文件 | 服务端校验节点、用户、类型和开放回合素材范围；不把封面当整段视频 |
| `@` 剪辑工程音视频 | 相对路径保留在工程上下文；`edit_media_info` 读取真实文件信息，`edit_view` 抽帧，`edit_transcribe` 转写 | 不拿相对路径冒充资产 ID；ASR 要求已导入并固定引用的资产，工程副本与资源库原文件 SHA-256 相同 |
| 当前预览、选中剪辑片段 | 从冻结工程快照调用固定版本 HyperFrames CLI 真正渲染，再作为图片送给模型 | 当前播放位置一张、每个选中片段中间位置一张；有版本保护，非完整片段视频 |
| TXT/MD/JSON/CSV/SRT/VTT | UTF-8 严格解码，实际文本加入官方 SDK 用户消息 | 文件 ≤64 KiB、单文件 ≤16000 字符、合计 ≤64000 字符；附件只作为用户数据 |

输入框统一“添加附件”，可选择文件、拖入和粘贴剪贴板文件；待发送文件可移除。音视频存入共享资产库，但不会自动加入轨道。最多 8 张图片和 8 项音视频/文字附件，引用计入上限。跨工程/会话切换期间的异步准备不会回写旧附件。

## 没有实现的能力

- 当前 SDK 模型输入类型为 `text/image`，尚未直接发送原生视频或原生音频。视频通过抽帧与 ASR，音频通过 ASR；这不是全帧、连续音画同步理解。
- 没有实时麦克风/摄像头输入；没有原生音乐、环境声、音效理解。
- 没有 PDF/DOCX/XLSX 等文档解析；入口明确拒绝，不以仅有文件名冒充读取正文。
- 工程生成或被修改且未重新保存到资产库的音频文件暂不直接转写，需先保存并导入原资源。
- ASR 时间为原素材时间。裁切入点、速度、变速曲线要映射到时间线，不自动承诺字幕已对齐。
- 抽帧只代表检查了相应时间点。默认抽样不能保证发现所有镜头、短暂文字或闪现问题；Agent 可按需指定更多时间点。

## 数据与执行保护

聊天入口规范化附件类型、资源归属和标题，再交给宿主。视频抽帧返回真实 JPEG，SDK 工具结果含 `image` 内容块；文本说明不复制 base64。工具图片同样遵循模型单张大小和数量限制。超过请求图片预算的旧图只在请求投影中缩减，官方会话原记录保留。

音视频文件不放聊天 JSON，记录所属资产或工程路径；文字正文与像素保存在官方会话日志中，对话列表只展示附件名称与类型。转写使用用户/项目/资源/语言/运行配置的稳定身份；断流和继续不会因相同输入新建重复任务。

原生媒体解析使用打包 FFmpeg/FFprobe、有界输出、超时和私有临时目录。工程抽帧使用冻结快照，不改工作文件和版本。ASR 工程源信息除运行端哈希验证外，还需 Go 查询真实工程资产固定引用，并对资源原文件哈希核对；HTML 声明本身不是授权。

## 已验证

- 实际 FFmpeg 视频带音轨：信息读取、多时间点 JPEG、音频无画面、越界拒绝、临时文件清理、原文件不变。
- 实际工程视频：抽帧、显式时间点不被默认数量截断、源入点/速度信息、修改副本拒绝转写。
- 官方 Pi 宿主 + 本地模拟模型：视频工具图像实际进入视觉请求；字幕正文实际进入 SDK；官方日志保留像素与正文，对话列表不重复存大正文。
- 本地 Whisper Base + 真实讲话样本：转写、时间戳和重开后复用持久结果。
- 类型/范围/文本附件校验、工程来源伪造拒绝、同资源重复转写复用同一任务。
- 前端附件分类、UTF-8/二进制拒绝、引用选择、聊天请求正文与类型检查。

没有使用用户付费模型进行真实供应商联调；供应商的视觉协议兼容性仍需在实际选定模型上验收。
