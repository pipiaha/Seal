## 用户可见变化

1. 生成前确认目标节点已经保存。生成结果回来时通过原任务绑定目标节点的生成字段，保留其他节点与人工编辑；失败不退回整画布快照写入。
2. 取回结果时显示已下载量、总大小、速度和进度。已成功且正在取回的任务可“停止取回”，之后从“继续取回”恢复原任务，不重新生成。上游结果尚在保存时等待原结果，不消耗传输错误的重试次数。
3. 声音参数为 boolean/number/string 时均可正常解析。视频解码失败后按需准备兼容副本；原视频不被替换。兼容副本缺失时不误用旧 ETag 或长期缓存错误状态。图片读取/解码失败有明确的重新加载入口，缩小画布后按钮仍可操作。
4. 更新下载后保留签名校验通过的压缩包，安装前在目标盘重新校验并只解压一次。准备失败不退出当前版本，保留下载内容以便重试。界面显示保存、校验、解压和重启阶段。保存失败可以返回或重试；“仍然更新”只在保存已经失败且没有活动写入时可选。
5. 音视频节点的字幕窗口可直接自动转写，再编辑、保存或导出 SRT。引用菜单切换分类和返回不会因输入框失焦立即关闭，选择不会穿透点击画布。生成历史只在媒体可见或预览被打开时读取媒体。

## Seal 专用适配

- 字幕控件调用 Seal 的 `/assistant/asr` 读取就绪状态，提交 `/timeline/transcriptions`，默认复用现有 ASR 设置；可选内置 Whisper Base 或已配置的在线服务。没有接入 BeefTV 云端 ASR 或账户服务。
- ASR 选择、语言和配置版本参与提交意图标识，原素材的毫秒时间戳保留。识别和关键词高亮分别维护运行状态；关闭窗口只停止监听，已受理任务仍在任务中心。
- FFmpeg 优先从 `BEEFTV_EDIT_HOST_ENTRY` 对应的 `media/ffmpeg/bin` 或主程序旁 `edit-host/media/ffmpeg/bin` 解析；保留显式环境覆盖和系统回退。
- 更新保留 Seal 的公钥、GitHub Releases、程序名称、工作区目录和 sidecars。当前发行使用完整 ZIP，未引入上游的 NSIS 安装器。安装帮助进程保留目录占用重试和整体回滚，补充占用/权限/空间错误提示。
- 加入上游针对 Vidstack 1.15.6 的生命周期补丁，防止控件卸载后预览定位回调访问销毁元素；依赖版本未升级。
- 生成结果进度只放在内存投影与前端瞬时 store，不将每次进度变化写入画布文档。
- 上游保存屏障只覆盖图片提交；Seal 将同一检查扩展到视频和音频，创建目标节点后先同步到画布 store 再保存，避免 React 延迟更新使保存读不到新节点。

## 验证证据

### 真实运行（无付费模型调用）

- 前端 TypeScript 检查及 Vite 构建通过。
- Windows 桌面预览版构建通过，并检查可执行文件包含本次前端入口。
- 真实无全局 FFmpeg PATH 环境下，使用 Seal 随包 FFmpeg 创建 HEVC 文件并转成 H.264，原文件哈希保持不变。
- Chromium 浏览器：图片传输失败和解码失败后重载，明暗主题、窄屏及 0.2 倍画布缩放，共四种场景通过。
- Chromium 浏览器：素材引用菜单的分类、返回、直接选择、上下键、Enter/Tab、Escape、外部点击和防点击穿透，八个交互场景通过。

### 本地接口／替身验证

- 保存屏障、节点删除、账号/画布切换、生成结果局部绑定、暂停取回及进度投影：相关前端专项检查通过。
- 使用本地 HTTP 服务制造中途断流，验证 Range 恢复、原任务身份、结果绑定、暂停/恢复、到期、进程关闭与 Worker 重启；对应后端专项检查通过。
- 视频缺失副本、播放变体 ETag、兼容预览申请、作用域改变后的下载拒绝：前后端专项检查通过。
- 使用本地签名更新包，验证只在安装时解压、准备失败保留原应用、解压取消、保存超时与迟到返回不能触发安装；更新专项检查通过。
- ASR 前端验证实际提交的 route、language、resourceId、clientOperationId，并保留返回的原素材时间戳；原有会话归属、关闭窗口与迟到结果检查通过。
