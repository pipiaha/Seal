# Agent 素材获取与完整剪辑链路核对

日期：2026-10-09。依据当前工作区源码及定向实际执行。结论：已有基础剪辑、动效检查和导出的执行能力，但“自主寻找素材 → 制作 → 复查成片 → 交付”尚未完全连通。不能以工具存在替代真实模型完整制作验收。

## 逐段核对

| 环节 | 现状 | 依据与边界 |
| --- | --- | --- |
| 读取当前画布、工程和显式素材引用 | 已有 | 当前画布 `canvas.get`、已引用 `asset.get`、`edit_read`、`hyperframes_context`、当前节点/资源音视频读取 |
| 自动在资产库搜索素材 | 缺少 | `agentops/scope.go` 不暴露 `asset.list/canvas.search`；没有按当前工程或指定素材集合检索的 Agent 工具 |
| 发现工程未上轨素材 | 部分 | UI 有 `/materials` 列表，但 Agent 的工程上下文以已有片段为主，没有独立工程素材列表工具；可通过显式 `@[media:...]` 读取已知文件 |
| 下载网页/公开视频、任意读取电脑目录 | 未提供 | 官方 SDK 内置工具关闭，仅装配产品自定义工具。Video Use 的上游下载脚本只保留为知识，产品执行合同不授予脚本运行能力 |
| 视频/图片理解与语音识别 | 已有抽帧/ASR链路 | 实际图片、视频时间点、持久转写；不是全帧音画理解，也不能识别音乐/音效 |
| 生图、生成视频、配音 | 两种权限模式 | 新对话默认请求批准，界面提供批准/拒绝；用户选择完全允许后界面自动提交现有渠道任务。后端持久校验模式，宿主不能自授权；配置变化或已停止/拒绝的方案不自动提交 |
| 参考图/视频/音频驱动生成 | Agent 提议入口不完整 | 底层任务支持 `referenceImages/referenceVideos/referenceAudios`，但 `media_generation_propose` 只有 kind/prompt/model 等参数，`useCreatorMediaActions` 未将本轮参考素材传入这些字段；不能把助手能看图等同于生成模型收到了参考图 |
| 生成完成自动继续 | 已接通界面协调 | 实际 `READY` 产物就绪后原会话自动续接；后端校验方案并从真实任务授予产物引用，持久登记一次续接。失败/拒绝也传回真实结果。软件关闭期间不会运行新的助手回合，原对话重开可续接未受理结果 |
| 导入素材 | 已有 | `hyperframes_import_asset` 把已保存且本轮明确引用的资源加入工程；Hypit 有独立作者工程导入工具。HyperFrames 桥接还要求启用匹配版本技能 |
| 基础剪辑 | 已有执行工具 | 元素切割、删除、文字/样式/时间属性修改，可表达移动、调整时长和轨道等；写入使用版本保护和稳定操作身份 |
| 字幕 | 可以编写字幕场景，专用流水线不足 | 可读取 ASR 并通过文字片段/候选场景制作字幕；没有独立结构化字幕创建、批量编辑及源时间到时间线映射工具，尤其变速曲线需额外处理 |
| 标题、动效、音频混合 | 已有 | HyperFrames HTML/CSS/GSAP 候选、绑定本地音视频、官方检查、入轨；复杂代码通过替换候选修改 |
| Hypit 制作 | 有执行桥接，未证明任意任务可自主完成 | Skill 读取、源文件写入、check/plan/build、任务状态、候选发布和入轨工具存在；生成素材仍走产品已批准渠道任务；具体整片效果需实际任务验收 |
| 工程画面检查 | 已有，但有模型上限适配缺口 | `edit_view` 能查看当前合成画面和素材；`hyperframes_snapshot` 固定 5 张、检查最多返回 8 张，外围模型图片限制会拒绝超量或超大的结果 |
| 导出 MP4 | 已有真实任务 | `hyperframes_export` 冻结工程并导出，`hyperframes_exports` 查询真实完成状态。工具启动任务不等于成片已完成 |
| 导出成片复查和自动归档 | 缺少完整 Agent 入口 | 工程截图可读，导出文件存于独立 exports 目录；当前 Agent 画面工具限制在工程工作文件，没有针对 exportId 的成片抽帧/音轨检测工具；保存到资产库仍由 UI 按钮触发 |
| 中断恢复 | 有记录，生成结果可原会话续接 | 会话、工作流、任务和操作回执可恢复；生成结果自动续接与停止状态持久化。默认每轮 180 秒、40 次模型请求、40 个工具步骤（可由运行配置覆盖）；仍不是软件关闭后持续运行的后台 Agent |

## 关键源码

- 素材范围与工具可见性：`backend/internal/agentops/scope.go`。
- SDK 工具装配与禁用内置工具：`agent-host/session-owner.mjs`。
- 基础剪辑：`agent-host/edit-bridge.mjs`。
- 动效、导入、导出：`agent-host/hyperframes-bridge.mjs`、`edit-host/hyperframes-scenes.mjs`。
- Hypit：`agent-host/hypit-bridge.mjs`。
- 生成提议：`agent-host/creator-bridge.mjs`、`backend/internal/handler/assistant_media.go`。
- 权限选择、批准与自动续接：`web/src/pages/canvas/creator-media-tasks.tsx`、`backend/internal/app/assistant_permissions.go`。
- 导出保存：`web/src/pages/edit/edit-assets.tsx`、`web/src/services/edit-export-assets.ts`。
- 图像大小/数量拒绝：`agent-host/turn-context.mjs`。

## 本轮验证

1. 实际 HyperFrames 集成测试通过：生成 GSAP 标题候选、官方浏览器检查及截图、版本保护入轨、撤销、切割、真实预览、冻结导出。FFprobe 确认 MP4 有音轨；像素与音频采样确认切割后源画面及淡入淡出时钟正确。
2. 剪辑、HyperFrames、创作工具桥接 5 个定向测试通过，覆盖范围、幂等、技能版本、检查图片、导出状态和只读模式。
3. 复现固定截图与模型上限不匹配：返回 5 张、模型上限 4 张，工具结果被 `image_input_invalid` 拒绝。数量保护本身正确，检查结果仍需按当前模型适配。
4. 工程 ASR 来源校验与任务复用测试通过。同步更新旧只读工具断言；此前新增 WAV 测试改用临时数据目录并清除其已核实生成文件，避免测试资源污染源码树。

本轮没有使用用户付费模型或生成渠道运行一部从头自动制作的成片。实际渲染测试验证执行底座，不能证明剪辑判断、审美质量、长任务自主完成率。

## 建议补齐顺序

1. 按已授权工程/素材集合提供分页素材列表与内容检索，让 Agent 真正找到素材。
2. 已连通制作方案、两种权限、持久任务状态、真实结果授权与原会话续接；后续可按需要把界面轮询改为任务事件订阅。
3. 补齐生成提议的结构化参考素材参数，并使用现有渠道能力约束。
4. 检查截图按模型数量/大小适配；提供字幕批量操作与源时间映射，减少依赖临时代码。
5. 增加按 exportId 读取成片画面/音轨信息与幂等保存到资产库的交付工具。
6. 用真实选定模型验收一条指定素材的制作任务，再测试含生成任务的长流程。
