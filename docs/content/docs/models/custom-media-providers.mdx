# 自定义图片、视频接口与本地 ComfyUI

在「模型配置」的图片或视频分类中添加渠道。普通服务填写服务地址和鉴权；本地 ComfyUI 选择对应预设。每个模型保存自己的接口或工作流配置，不需要手写配置文件。

## 供应商预设

图片和视频分类均提供 Agnes AI，添加时默认国内站 `https://api.agnes-ai.cn/v1`。在「服务站点」中也可选择国际站 `https://apihub.agnes-ai.com/v1`。按创建 API Key 的控制台选择地址；国内站与国际站的密钥不应混用，否则可能返回 `401 Invalid token`。切换站点只调整服务地址，保留密钥、模型与协议；已有渠道不会自动切换站点。

- 图片默认模型 `agnes-image-2.5-flash`：复用已有 Agnes Image 协议，JSON `POST /v1/images/generations`，参考图片映射到 `extra_body.image`，输出请求 URL。可在现有能力设置中调整比例、1K／2K／4K 档，实际尺寸可能由供应商归一化。不使用 OpenAI 的 `/images/edits`。
- 视频默认模型 `agnes-video-2.5-flash`：已有 Agnes 原生异步协议。可手动添加 `agnes-video-2.5` 等实际开通的模型 ID。参考素材需供应商可读取的公开 URL；添加预设不代表所有本地素材可以直接发送。

协议依据：[国内图片说明](https://wiki.agnes-ai.cn/zh-Hans/docs/agnes-image-20-flash)、[国际图片说明](https://wiki.agnes-ai.com/en/docs/agnes-image-25-flash)、[视频说明](https://wiki.agnes-ai.com/en/docs/agnes-video-25)。预设不包含凭证，也不自动发起生成。

## 普通 HTTP 服务

选择「自定义服务」后，添加渠道弹窗的「高级设置」默认展开，直接显示接口配置，无需先添加模型。调用方式默认是「自定义 HTTP 接口」，也可以改用已有供应商协议。自定义请求头、素材域名等位于同一区域的「附加连接参数」，默认收起。

先填写接口配置，再在下方添加模型 ID。新增模型沿用当前接口配置；添加多个模型后，可在「配置模型」中切换并分别调整。已有渠道的接口不会自动改成自定义协议。

模型的输入限制、比例、时长等在「生成参数与连接测试」中调整，这里不再重复显示接口配置。生成测试仍需确认后才会提交真实任务。

1. 在调用方式中选择「自定义 HTTP 接口」，直接编辑 JavaScript 配置，不需要逐行填写参数映射。
2. 选择同步图片、异步视频、数组与嵌套参数或 Multipart 模板，用真实供应商文档替换路径和字段。
3. 可从「插入变量」选择模型、提示词、时长和素材。下方展开示例输入后，点击「检查并预览请求」查看最终参数；预览不会请求供应商，不生成或计费。还可填写供应商响应 JSON 验证提取规则。
4. 可直接把供应商 API 文档发给 Seal 创作助手，要求它配置指定图片／视频模型。助手会读取当前渠道、编写脚本、检查并直接保存，界面自动刷新。「复制给助手的配置说明」提供可选的格式说明；按钮本身只复制，不调用模型。其他助手生成的脚本仍可手动粘贴或导入。
5. 先添加模型 ID，再保存。保存时也会检查脚本。每个模型分别保存配置，已提交的任务继续使用提交时的配置快照。

### 让创作助手直接配置

在画布或剪辑工程的助手中提供服务地址、模型 ID、API Key 和接口文档，例如：「根据这份文档，给我的视频渠道配置这个模型，检查后连同我提供的 Key 直接保存，保留其他模型。」已有渠道无需再次提供密钥。助手读取渠道时只获得名称、地址、模型和脱敏脚本，不会读取已保存的 API Key 或请求头值。

助手可以新建自定义 HTTP 渠道，或更新已有渠道的一个图片／视频模型。用户在对话中提供的 API Key 通过保存工具的 `apiKey` 字段一并写入现有加密配置；非空新 Key 替换原值，省略或留空保留原值。执行记录和保存结果不回显 Key。已有渠道的服务地址、鉴权方式和请求头值仍由设置页管理，不能让助手把原密钥改发到其他地址。默认模型仅在用户要求时设置。文字模型、内置／托管渠道和 ComfyUI 工作流不通过此工具修改。

在对话中提供 Key 时，它属于发送给当前助手模型的对话内容，并随现有会话保存；也可以继续在「模型配置」中填写，不经过助手对话。Key 不应写入接口脚本、URL 或 Skill 文件。

保存前重新检查脚本，以当前配置版本保护人工改动。同一提交重放不重复创建渠道。前端保存遇到并发修改时，只合并互不冲突的字段；同一字段的冲突明确保留为待处理，不整份覆盖远端配置。保存不会进行真实生成，不能把「配置已保存」说成「接口已生成验证成功」。

路径 `/jobs/{task_id}` 中的任务 ID 会经过路径转义。默认路径追加在渠道基础地址后；操作中设置 `originPath: true` 可从域名根开始。路径不能指向另一台服务。URL 查询参数填写在操作的 `query` 对象中。

响应路径支持嵌套与数组，例如 `data.task_id`、`data.status`、`data.*.url`。非标准状态可配置为：

```json
{ "0": "pending", "1": "processing", "2": "succeeded", "3": "failed", "4": "cancelled" }
```

状态仍在处理中时，即便返回了占位 URL，也不会下载并宣布完成。

### JavaScript 接口配置

配置是一个 JavaScript **对象表达式**，无需 `import`、`export` 或 `fetch`。Seal 在 Go 运行端内嵌的 JavaScript 引擎中进行参数转换；提交、鉴权、文件上传、轮询、取消与下载继续使用现有任务执行器。脚本不提供文件、环境变量、渠道密钥或网络 API；不支持异步函数。源码上限 64 KiB，每次转换和响应提取共用 200 毫秒执行限时。

直接可用的变量包括 `model`、`prompt`、`seconds`（数字）、`aspectRatio`、`resolution`、`quality`、`count`、`generateAudio`、`watermark`、`size`、`extra`。`images/videos/audios` 是 URL 或 Data URL 字符串数组；`request.images/videos/audios` 是完整素材对象数组。`firstFrame/lastFrame` 是明确标记了首尾帧角色的图片链接，没有时为空字符串。查询阶段可引用 `taskId`。

```javascript
{
  requiresPublicMediaUrls: true,
  create: {
    method: "POST",
    path: "/generate",
    contentType: "application/json",
    body: {
      model,
      params: [
        { type: "text", value: prompt },
        ...images.map(url => ({ type: "image", value: url })),
        ...videos.map(url => ({ type: "video", value: url }))
      ],
      options: { seconds, aspect_ratio: aspectRatio }
    }
  },
  poll: { method: "GET", path: "/tasks/{task_id}" },
  response: {
    taskId: data => data.data.task_id,
    status: "data.status",
    statusMap: { "0": "pending", "1": "processing", "2": "succeeded", "3": "failed" },
    result: data => data.data.outputs?.map(item => item.url) || [],
    error: data => data.error?.message || null,
    message: data => data.message || ""
  }
}
```

数组有固定顺序时，直接写 `params: [prompt, images[0], images[1], seconds]`；需要名为 `param[0]` 的顶层字段时写 `body: { "param[0]": prompt, "param[1]": images[0] }`。字段名和数组的区别以供应商文档为准，不能把数组下标当成普通字段名。没有参考素材的场景应使用条件表达式或 `.map()`，避免强行读取不存在的元素。

`response.taskId/status/result/error/message/base64` 可以填字段路径或同步函数；`result` 返回链接或链接数组，`base64` 返回编码或编码数组。裸 Base64 需指定 `inlineMime`，例如 `image/png`。异步接口必须配置任务 ID 与状态提取规则；处理中返回占位链接不会提前下载。供应商返回失败时，`error` 返回错误信息，正常时返回 `null`，否则会被当作失败。

Multipart 操作的文件字段示例：`files: request.images.map(image => ({ name: "image", source: image }))`。这引用已授权的素材，不是本机路径。独立鉴权下载可配置 `result: { method: "GET", path: "/tasks/{task_id}/file" }`。供应商支持定向取消时配置 `cancel` 操作；收到 HTTP 成功后仍核对任务终态，只有明确取消状态才确认取消。操作结构应固定，条件表达式用于参数值和结果提取。

鉴权选择「API Key / Bearer」「指定请求头」或「无需鉴权」。密钥和请求头在渠道连接处填写，不能硬编码到脚本、查询参数或工作流中。要求公开素材 URL 的接口设置 `requiresPublicMediaUrls: true`；本地素材无法公开读取时会明确报错。

接口配置支持导入 `.js` 对象表达式，以及导入、导出 Seal JSON 配置包。配置包仅携带脚本／工作流和能力声明，不包含渠道地址、密钥和自定义请求头；明确的凭证字段会拒绝导入或导出。任意代码字符串不能可靠自动识别所有硬编码秘密，不要在脚本内写密钥。分享前检查提示词、文件名和其他业务内容。已有声明式接口配置仍可执行，编辑器会把可转换的规则展示为 JavaScript；不支持的特殊表达式保留原配置并提示选择模板重新配置。

## 本地 ComfyUI

先启动自己的 ComfyUI，默认地址 `http://127.0.0.1:8188`。Seal 不安装 ComfyUI、Python、模型或自定义节点。

1. 选择「本地 ComfyUI」预设，按需填写地址及鉴权。
2. 点击「测试连接」，成功后读取本机节点与模型选项。「工作流」区域支持「导入文件」或「粘贴 JSON」：可以使用 ComfyUI 导出的 **API 格式** JSON，也可以自行编写相同格式。点击「检查并应用」后再保存渠道。普通画布 JSON 不能提交；这里不提供 Seal 配置包导入、导出。
3. 导入时尽可能识别正向提示词和最终输出。无法确定时提示用户选择；完整节点图、字段绑定和输出字段默认折叠在「高级设置」中。主界面显示工作流名称、模型及常用参数，保留负向提示词等其他输入。
4. 有参考图时，绑定 `LoadImage` 等节点的图片输入；可调整图片索引和必填要求。
5. 选择最终输出节点。图片使用 `images`；VHS 视频通常使用 `gifs`，部分节点使用 `videos`。具体以节点返回结构为准。
6. 点击「刷新本机模型」，仅读取 `/system_stats` 和 `/object_info`，不生成。Seal 根据该实例节点的真实枚举列出 checkpoint、扩散模型、文本编码器、VAE、LoRA 等可选文件；安装新模型后再次刷新即可。更换文件会写入工作流实际输入，保留其他节点与连线。缺失文件保留显示并提示，切换模型架构仍需匹配的工作流。执行前也会核对节点是否安装。

已保存工作流可以在「高级设置 → 编辑 JSON」中继续修改。格式错误不会覆盖原工作流；取消编辑也不改变配置。编辑现有 JSON 时尽量保留未变节点的字段绑定与输出选择；粘贴新的工作流则重新识别。格式通过及本机模型可见不代表 GPU 已执行成功，保存与检查不会提交生成任务。

只覆盖明确启用的标量字段，保持数值、布尔类型与节点连线。图像通过 `/upload/image` 上传，工作流通过 `/prompt` 提交，使用 `prompt_id` 查询 `/history` 与 `/queue`，最终由 `/view` 下载并进入现有资产库。

目前支持提示词和参考图片输入、图片或视频输出。参考视频、参考音频、蒙版文件的专用上传协议尚未接入；不会把它们假装当图片上传。自定义输出节点必须提供可通过 `/view` 下载的文件描述；仅返回服务器绝对路径的节点不适用。

提交后先保存原任务 ID，再查询结果。恢复已有任务不会再次上传或提交。若队列、历史已清理而找不到原任务，会明确失败，不自动重新生成。进度目前通过每两秒读取队列、历史展示「排队中／正在生成」；没有 WebSocket 节点百分比。

支持定向取消的 ComfyUI 使用 `/api/jobs/{id}/cancel`。旧版本只对排队任务发送 `/queue` 删除并核对结果；运行中的任务如果无法安全定向停止，会报告取消待确认，不调用全局 `/interrupt`。

只有本地工作区启用 ComfyUI 连接。回环访问只开放给这个连接器，不能跨地址重定向；普通联网、下载和其他 Provider 的私网限制保持生效。局域网地址仍需通过 `CANVAS_ALLOWED_PRIVATE_UPSTREAM_HOSTS` 明确允许。

## 供应商预设与模型刷新

预设提供连接地址、协议及初始推荐值，不是模型允许列表。有模型目录接口的渠道可以在管理页「刷新模型」，也可以在渠道列表逐个或批量刷新。没有默认目录的服务允许手工添加任意模型 ID；高级设置中的「模型目录接口」可配置供应商提供的同站点路径。目录格式支持 OpenAI、Gemini、Anthropic，原生 Gemini 与 Anthropic 目录支持分页；鉴权沿用渠道的 Bearer、指定请求头或无需鉴权设置。

发现的目录与用户启用的模型分别保存。刷新不会自动启用新增型号、替换默认模型、删除手工模型或覆盖已有参数、脚本与工作流。没有类型信息的条目会标为「类型未标明」，可以选择加入当前类型，并配置实际协议。曾被目录列出、后来消失的条目会提示「目录未再列出」，不会擅自删除。

目录缓存存入按当前用户及连接配置隔离的 IndexedDB，显示最近读取时间；超过一天提示建议刷新。地址、鉴权或目录接口变化后不会沿用旧连接的目录。缓存键使用连接摘要，不保存密钥；目录数据不等于账号实际调用权限。刷新失败显示真实错误并保留上次列表；目录缓存不可用时仍可使用手工模型。ComfyUI 使用节点枚举而非远端模型目录，不套用 OpenAI 的 `/models` 协议。

## 任务与验收

画布和助手沿用同一套生成任务。任务中保存提交时的接口／工作流快照与受保护的密钥；后续修改渠道不重写已提交任务。任务详情显示实际渠道名、服务主机及协议；调用日志保留脱敏请求信息。

连接检查不等于生成成功。模型的生成测试会实际提交任务，可能计费。开发验证使用本地 HTTP 替身覆盖配置传递、字段映射、上传、回执、续接与取消；实际服务账户、GPU 模型与第三方自定义节点需要用户自己的环境验收。
